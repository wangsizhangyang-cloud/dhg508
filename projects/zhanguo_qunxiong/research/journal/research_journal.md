**关键发现**：

1. **史料被做成了可查询的数据结构**：`battle` 每条带原文与出处，`rating` 每条带 `rationale`；43 条外部佐证逐字比对《左传》《战国策》《国语》《吴子》《孙子兵法》。数据库本身就是一份可复核的史学作业。
2. **数值是史学论点的翻译**：13 条克制直接承接《荀子·议兵》的「齐技击 < 魏武卒 < 秦锐士」；魏武卒的高维持费对应「数年而衰、其税必寡」；车兵编制引《司马法》。
3. **地图是程序化历史地理**：87 省以史载城邑真实经纬为锚点，46×28 网格 + 加权 Voronoi + 六边形采样 + Catmull-Rom；8 控制点二次拟合（残差 ≤ 3.1px）；每省带 `vol/cite`；海/山/河/湖全部自绘。
4. **LLM 是演员，世界是导演**：幽王只接收纪年、感知、记忆、禁句；只输出单动作 JSON；`goto` 白名单；死亡封殿；复读用二元组 Dice ≥ 0.72 判重，重试一次后由脚本接管；本地代理把 Key 留在本机。
5. **历史锚点是有意的教学设计**：骊山之难固定发生；先取镐京也会被犬戎卷出；勤王后得锐士 50；犬戎转守。玩家的自由在「如何应对」，不在「是否让它发生」。
6. **一套数据支撑五种产物**：SQLite → 图鉴 → 190 张雷达 → 兵种导览 → Web 游戏 → Godot JSON。`export_godot_data.mjs` 用 Node `vm` 沙箱读浏览器全局变量，避免数值分叉。
7. **边界被写进交付物**：服装报告区分明文与艺术演绎；地图注明几何虚构；`questions.md` 列越国东界异说、LLM 史限、成本牌价、围城平衡等 9 类未解。
8. **零依赖是约束驱动的架构**：单 HTML 双击即玩；只有用 LLM 才起本地 Node 代理；简繁只做显示层（OpenCC 2587/2853 对）；250ms 防抖；12 回合 AI 压测。
9. **AI 美术是规则系统**：190 张立绘按 `era/state/role` 映射四套服制；`ai_log.txt` 保留 HTTP 402 失败与重试；`data.js` 每位武将带 `costume` 字段。

- **阅读**：下载 15 项 OA 全文，逐页抽取；5 个 agent 分主题阅读（补读 Harnes 2025、Karn 2024）；关键短引做规范化抽查（`../outputs/quote-spotcheck3.json`）。
- **权威性重筛**：BaiJia（预印本）、Nadjamuddin 2026（弱控制）、Nurgaliyeva 2024（概念文章）、Grundmann 2019（博士论文）从核心证据降为背景/线索；补读 Harnes 2025（HERJ 41 项综述）与 Karn 2024（HERJ 设计工具）。
- **主要发现**：
  - 固定锚点 + 战术自由有类型学支持（Belyaev, PDF p.7；Fagan, p.14）；
  - 规则本身可承载史学论点（Belyaev, p.14；O'Donnell, p.7）；
  - 共情的实证研究支持「多视角 + 语境化 + 证据」，不支持「扮演 = 共情」；第一人称写作提高 presentism（Harnes, pp.7–12, 14；Karn 2024, pp.4–11）；
  - LLM 记忆/时间点约束有研究支持，但「世界判定」无直接文献（Park, pp.15, 17–18；TimeChara, p.8）；
  - 气候只能做压力，不能做剧本（Li et al., pp.1–5）；

  - 周王权是「命令—承诺」关系（Grundmann, p.183，B 级）。
