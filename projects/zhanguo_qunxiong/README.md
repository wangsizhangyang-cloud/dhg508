# 战国群雄（zhanguo_qunxiong）

以《史记》《国语》《战国策》等原文为数据源的战国历史模拟。玩家执西垂之秦（秦襄公），在「骊山之难」前后决定勤王与否、何时出兵、从哪省出、出多少；周幽王是一个受记忆与感知约束的 agent。

## 为什么是模拟，不是电影

电影可以告诉你「烽火失信 → 诸侯不至 → 西周亡」。只有让你自己决定「出多少兵、走哪条路、何时动」，才会体验到勤王是资源、距离、时机与后果的权衡。骊山之难是历史锚点，不可改写；玩家的自由在**如何应对**，不在**是否让它发生**。这是「在不可逆约束下做选择」的训练。

## 规模

- 87 个省、13 国、15 兵种、13 条克制、16 张将领技卡；
- 190 位武将、1215 条战绩、190 条六维评分、190 张雷达图、190 张人物立绘；
- 6 课教学关、周幽王 agent、简繁显示切换、本地 LLM 代理；
- Web 规则原型 + Godot 4 垂直切片（87 省 / 190 将 / 15 兵种 / 回合骨架）。

## 数据与证据

- 每条战绩带 `original_text` 与 `source_chapter/citation`；43 条外部佐证逐字比对《左传》《战国策》《国语》《吴子》《孙子兵法》。
- 每个省带 `vol/cite`（规模史据）；地图与海岸/河流/山脉全部自绘，不用外部底图。
- 服装报告区分「明文」与「艺术化演绎」；设计文档有 evidenced / inferred / invented 分级表。
- 未决问题见 `questions.md`，不假装已经全部解决。
