# 设计

## 目标

1. 为中国古代武将建一个**关系型**数据库：生卒年份、参与战役、功绩、官职、描述，每行带出处。
2. 出处只用**史书原文**，不用维基百科条目。原文取自中文维基文库（公有领域古籍全文），
   逐字可核。维基百科只用于最初定位篇目，**不作为 source**。
3. 每行都有 `source`（书名）与 `source_locator`（卷/篇，即「页」）、`source_quote`（逐字引文）
   和 `note`（存疑处）。标准化日期/名字时，原文另存 `*_raw` / `*_original`，换算规则入
   `conversions` 与 `calendar` 表。
4. **可增长**：新增材料 = 往 `data/generals/` 加一个同构 JSON，再跑 `build_db.py`；
   老行以 `key` 为准，不会被破坏。步骤见 `research/notes/how-to-grow.md`。

## 收录范围

36 位武将，取自 25 篇史书列传，跨 秦／西楚／兩漢／三國／兩晉／唐／南宋／明。

## 取舍

- **原始出处**：中文维基文库的古籍全文（《史記》《漢書》《後漢書》《三國志》《晉書》
  《舊唐書》《新唐書》《宋史》《明史》）。理由：逐字可核、公有领域、可用网络直接取。
- **多对多**：「将—役」用联结表 `general_battles`。同名战役按 `(名, 公元年, 原文年)` 合并，
  避免误并：李廣、衛青各出雁門、年份不同，故并存两行；垓下、漠北等同役则合并。
- **日期换算**：保留原文（`year_raw` / `born_raw` / `died_raw`），公元年以负数表示公元前；
  各政权的纪年基准写在 `calendar`，逐条换算写在 `conversions`。
- **名字标准化**：`name_chn` 为标准名，`name_original` 保留史书原写（如項羽，史作「項籍」）。
- **schema 跟着问题走**：只留回答所需列；一行一件事，每行带出处与存疑备注。

## 边界

- 生年**多不载于史**，`born_year` 多为 `null`，不臆补。
- 卒年若史书未直书（岳飛、戚繼光、俞大猷），从阙并记 `note`；呂布卒年 199 与「建安三年」有歧，
  照实转述。
- 只覆盖已抽到的 36 将；库外内容不作答，见 `skills/general-db/SKILL.md`。
