# 设计

## 目标

1. 为北京故宫的建筑找到**没有人物、只含建筑**的在线照片，同一建筑只取一张，并注明出处。
2. 把每座建筑的史实抽成结构化的一行行记录（`id / date / fact / names / places / source`）。
3. 存进 SQLite，并抽若干行回原文核对。

## 取舍

- **影像来源**：Wikimedia Commons。理由：可直接下载、许可与作者可查（CC/CC0），
  适合逐张注明出处。
- **无人像**：热门大殿的外景几乎都有人。策略是先找「明确可辨识且无人」的视角——
  殿内宝座/匾额、出檐与脊兽细部、雪中露台、夜间/黄昏长曝光、护城河对岸远景、匾额近景。
  选图以**逐个全尺寸核验**为准则，不靠文件名或缩略图。
- **事实来源**：维基百科中英文条目 + 故宫博物院官网页面。原文全部存到 `sources/raw/`。
- **schema 跟着材料走**：只留回答需要的列；一行一个事实；每行带出处与存疑备注。
- **归属**：事实用 `building_id` 挂到建筑；照片与其许可挂在 `buildings` 行上。

## 边界

- 影像的「无人像」是核验当时（2026-09）的图片内容判断；若原图被替换，需重核。
- 事实只覆盖已抽到的行；库外的内容不回答。存疑照实转述，不替它选一个。
